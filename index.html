Use the Loop Method to Get Better Results From ChatGPT

Improve any repeated AI workflow — video editing, image generation, or anything else — by putting it through a self-review cycle instead of accepting the first pass.

  1. Open ChatGPT Work and find a workflow that needs improvement: a skill, project folder, or process that works inconsistently.
  2. Prompt: “Improve this workflow in 3 loops. Have a panel of sub-agents adversarially review each loop. Done when [definition of done].”
  3. Use /goal to assign a deliverable you want the workflow to build. Let it run three loops, taking 15 minutes to an hour.
  4. Test the improved workflow. If it still needs work, tell Codex to codify the ambiguous parts into scripts.

Pro tip: Turn this self-improvement process into a reusable skill, then run it whenever a workflow becomes inconsistent. Full guide. Rundown AI
